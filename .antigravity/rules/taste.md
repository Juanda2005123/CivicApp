# Design Taste & Anti-Cliché Guidelines

> **Authority Reference:** [Dub.co (Steven Tey)](https://github.com/steven-tey/dub)  
> **Role:** Principal Frontend Architect  
> **Status:** Mandatory Rule Set

---

## 1. Anti-AI Visual Cliché Heuristics

Modern web development generated by automated models is saturated with predictable aesthetic tropes that signal low-effort prototyping rather than enterprise craft. Every layout generated under this system must adhere to these prohibitions:

### 1.1. Gradients & Color Restraint
* **Banned:** Saturated violet-to-cyan or purple-to-pink gradient backgrounds, text fills, and borders without specific brand justification.
* **Banned:** Rainbow ambient glows behind cards and buttons.
* **Rule:** Interfaces must be built primarily on monochromatic foundations. Accent color must be functional (conveying status, primary action, or brand identity), applied with precision to no more than 10-15% of the visual space.
* **Color Temperature:** Keep neutral tones homogeneous (pure neutral or zinc/slate). Never mix warm creamy grays with cold steel blues on the same page.

### 1.2. Elevation & Lighting Geometry
* **Banned:** Diffuse, high-radius floating shadows (`shadow-2xl`, `shadow-indigo-500/50`) that disconnect components from the surface plane.
* **Rule (Borders over Shadows):** Define depth primarily through 1px border contrast (`border-neutral-200 dark:border-neutral-800`), supplemented by subtle, directional micro-shadows:
  ```css
  /* Preferred subtle elevation */
  box-shadow: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  /* Or Tailwind */
  shadow-xs border border-neutral-200/80 dark:border-neutral-800/80
  ```
* **Light Source:** Assume a single overhead light source. Top borders may feature an inner highlight line (`inset 0 1px 0 0 rgba(255,255,255,0.06)`), but bottom borders must stay grounded.

## 2. Sober Typography & Vertical Rhythm

### 2.1. Type Hierarchy
* **Font Stacks:** Prefer clean, modern neo-grotesque sans-serifs (Geist Sans, Inter, SF Pro Display, or system native stacks).
* **Tracking Rules:**
  * Headings (`text-2xl` and above): Tight tracking (`tracking-tight` or `-0.02em` to `-0.03em`) to increase optical density and authority.
  * Body copy (`text-sm`, `text-base`): Normal tracking (`tracking-normal`).
  * Micro-labels, badges, metadata (`text-xs` uppercase): Expanded tracking (`tracking-wider` or `0.05em`).
* **Weights:** Limit weight variants within a single view to three weights: Regular (`font-normal` / 400), Medium (`font-medium` / 500) for interactive elements, and Semi-Bold (`font-semibold` / 600) for structural headings. Avoid indiscriminate use of `font-bold` (700) or `font-black` (900).

### 2.2. Vertical Rhythm & Spacing Cadence
* Strictly align spacing to a 4px / 8px baseline grid (`gap-1`, `gap-2`, `gap-4`, `gap-6`, `gap-8`).
* Line heights must scale inversely to font size:
  * Display titles (32px+): `leading-none` or `leading-tight` (1.1 - 1.2).
  * Body text (14px - 16px): `leading-relaxed` (1.5 - 1.6) to guarantee legibility.

## 3. Microinteractions & Tactile Feedback

Tactile refinement transforms a static interface into a high-grade product.

* **Transitions:**
  * Standard duration: `150ms` to `200ms`. Never exceed `300ms` for regular UI transitions (dropdowns, tooltips, buttons).
  * Timing function: `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out-quint) or standard Tailwind `ease-out`. Avoid sluggish linear or generic `ease-in-out` on interactive controls.
* **Button Affordances:**
  * Active state feedback is required: `active:scale-[0.98]` or `active:translate-y-[0.5px]`.
  * Hover states must prioritize subtle luminance or border brightness shifts over drastic color morphs.
* **Loading & State Transitions:**
  * Interactive controls must never shift the layout during loading states. Maintain fixed dimensions (`w-fit min-w-[...]`) when swapping text for spinners.

## 4. Empty States & Skeleton Placeholders

### 4.1. Empty State Architecture
Empty states must never be dead ends or decorative art galleries.
* **Layout:** Centered or left-aligned contained card with a subtle dashed or solid border (`border-dashed border-neutral-300 dark:border-neutral-800`).
* **Visual Anchor:** Use a single, clean monochrome iconography container (`w-10 h-10 rounded-lg bg-neutral-100 dark:bg-neutral-800 flex items-center justify-center text-neutral-600 dark:text-neutral-400`).
* **Hierarchy:**
  1. Primary Title: Concise, clear (`text-sm font-medium text-neutral-900 dark:text-neutral-100`).
  2. Description: Instructive, specifying what is missing and how to resolve it (`text-xs text-neutral-500 max-w-sm`).
  3. Action CTA: Direct primary action button (`h-8 text-xs font-medium`).

### 4.2. Skeletons
* Skeletons must mirror the exact layout, aspect ratio, and typography metrics of the final loaded component.
* Avoid generic full-page spinner overlays.
* Pulse animation must be soft: `animate-pulse duration-1000` with muted gray backgrounds (`bg-neutral-100 dark:bg-neutral-800/60`).

---

## 5. Architectural Checklist Before Review
- [ ] No saturated purple/violet decorative gradients without product reason.
- [ ] No `shadow-2xl` or ungrounded colored glow drop shadows.
- [ ] Typography scale follows strict tracking and line-height constraints.
- [ ] Active and hover states have subtle, snappy microinteractions (<= 200ms).
- [ ] Empty states contain an icon, explanatory copy, and an actionable CTA.
